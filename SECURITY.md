# Security

Do not post credentials, live session data, device dumps, network captures, or exploitable details in public issues or pull requests. Use the repository's private vulnerability reporting feature when available. If it is unavailable, open a public issue containing no sensitive details and ask the maintainer for a private contact method before sharing details.

See [secret safety](docs/05-security.md) for repository scanning and response to accidental disclosure. This project relies on device modification and an undocumented web interface; review each integration's threat and recovery notes before use.
