# Integration index

Only routes listed as **Available** are selectable by `dot-connect-init`. Available means documented and testable, not universally compatible or guaranteed to work.

| Route | Availability | Verified scope | Guide |
| --- | --- | --- | --- |
| Yandex Station | Available, experimental | One Lite 1 (`YNDX-00025`, `yandexmicro`) on firmware `0.369.1.46.4778262442.20261013.297` | [Guide](yandex-station/README.md) |

Bluetooth accessories, watches, other speakers, and service integrations are ideas, not supported routes. Propose or add one using [the integration guide](../docs/adding-integrations.md).
